# Overview

Copy page

Composio powers tool discovery, execution, authentication, and context management for your AI agents with 1000+ toolkits. This reference covers our REST APIs and SDKs.

## [Quick Reference](https://docs.composio.dev/reference\#quick-reference)

- **Base URL**: `https://backend.composio.dev/api/v3.1`
- **[Authenticating to Composio](https://docs.composio.dev/reference/authenticating-to-composio)**: `x-api-key` (project) or `x-org-api-key` (organization) header
- **[Rate Limits](https://docs.composio.dev/reference/rate-limits)**: 2K-10K requests per minute (plan-dependent)

## [REST API](https://docs.composio.dev/reference\#rest-api)

| API | Description |
| --- | --- |
| [Tool Router](https://docs.composio.dev/reference/api-reference/tool-router) | Session-based API for AI agents to discover and execute tools |
| [Tools](https://docs.composio.dev/reference/api-reference/tools) | List, search, and execute individual actions |
| [Connected Accounts](https://docs.composio.dev/reference/api-reference/connected-accounts) | Manage user OAuth connections to apps |
| [Auth Configs](https://docs.composio.dev/reference/api-reference/auth-configs) | Configure how users authenticate to toolkits |
| [Triggers](https://docs.composio.dev/reference/api-reference/triggers) | Subscribe to webhooks from connected apps |
| [Toolkits](https://docs.composio.dev/reference/api-reference/toolkits) | Browse available apps and their tools |
