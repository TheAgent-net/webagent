A front door for AI agents

JSON in, JSON out

Request

curl -X POST https://agentnet.it.com/t/acme/chat \
  -H "Content-Type: application/json" \
  -d '{"text": "Compare plans for a five-person team"}'

Reply

{
  "lastText": "The Team plan fits a team of five. It covers up to 10 seats.",
  "session": "ses_4k2p",
  "visuals": [{ "type": "table", "source": "/pricing" }]
}

  • MCP and llms.txt

    Agents connect over MCP and call one tool, ask. They can also read /llms.txt and the agent card at /.well-known/agent-card.json.

  • Real agents, verified

    We check signed requests (Web Bot Auth, RFC 9421) and published IP ranges. A real agent is told apart from a look-alike.
