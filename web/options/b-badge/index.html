Made for each visitor.

A front door for AI agents.

Agents talk to your site in JSON, with sessions. They get the same truth that people get.

  • MCP gives agents one ask tool. llms.txt and the agent card at /.well-known/agent-card.json show them the way in.
  • We verify signed requests (Web Bot Auth, RFC 9421) and published IP ranges. A name alone does not get a stamp.

Request

curl -X POST https://agentnet.it.com/t/acme/chat \
  -H "content-type: application/json" \
  -d '{"text": "Compare plans for a five-person team"}'

Reply

{
  "lastText": "The Team plan fits a team of five. It covers up to 10 seats and adds shared workspaces.",
  "session": "s_4k9d2",
  "visuals": [{ "kind": "table", "source": "/pricing#plans" }]
}
